# 🤝 ДоброБот — бот для волонтёров

Проект представляет собой бота для автоматизации работы волонтёрского отряда: создание анонсов
мероприятий, сбор заявок на участие и учёт записавшихся. Актуальная версия проекта — **v2**.

---

## 🛠 Стек проекта

| Категория | Технологии |
|---|---|
| Язык | Python 3.12 |
| Библиотеки | aiogram 3, SQLAlchemy, dotenv |
| База данных | SQLite |
| Тестирование | pytest, pytest-asyncio |
| Инструменты | Git, GitHub Actions (CI), flake8, black |

---

## ⚙️ Реализованный функционал

- **Для волонтёров** — просмотр мероприятий, запись в один клик через inline-кнопки,
  счётчик участников обновляется прямо в сообщении.
- **Для организаторов** — создание мероприятий через FSM-диалог, указание лимитов
  и ссылок на чаты, просмотр списка записавшихся.
- **Инфраструктура** — конфигурация через `.env`, логирование, работа с базой
  через SQLAlchemy.

---

## 🧪 Тестирование

В проекте настроен процесс контроля качества:

- Тесты на `pytest` — в папке `v2/tests/`.
- Линтер **flake8** (конфиг — `.flake8` в корне репозитория) и форматтер **black**.
- Автоматическая проверка при каждом пуше через **GitHub Actions**:

  ```
  установка зависимостей → flake8 → black → pytest
  ```

## 🚀 Запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/fyder551/DobroBot.git
   ```
2. Перейдите в папку проекта:
   ```bash
   cd v2
   ```
3. Создайте виртуальное окружение и активируйте его:
   ```bash
   python -m venv venv
   venv\Scripts\activate
   ```
4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
5. Создайте файл `.env` и добавьте свои токены:
   ```
   BOT_TOKEN=<токен от @BotFather>
   GROUP_ID=<id группы для уведомлений>
   ```
6. Запустите бота:
   ```bash
   python run.py
   ```

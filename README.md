# ДоброБот — бот для волонтёрского отряда

Проект представляет собой бота для автоматизации работы волонтёрского отряда: создание анонсов
мероприятий, сбор заявок на участие и учёт записавшихся. Актуальная версия проекта — **v2**,
расположена в одноимённой папке.

## Стек проекта
* **Язык:** Python 3.12
* **Библиотеки:** aiogram 3 (для работы с API), SQLAlchemy (ORM), dotenv.
* **База данных:** SQLite.
* **Тестирование:** Pytest, pytest-asyncio.
* **Инструменты:** Git, GitHub Actions (CI), flake8, black.

## Реализованный функционал
* **Для волонтёров:** просмотр мероприятий, запись в один клик через inline-кнопки,
  счётчик участников обновляется прямо в сообщении.
* **Для организаторов:** создание мероприятий через FSM-диалог, указание лимитов и ссылок на чаты,
  просмотр списка записавшихся.
* **Инфраструктура:** конфигурация через `.env`, логирование, состояние пользователей (FSM),
  работа с базой через SQLAlchemy.

## Тестирование
В проекте настроен процесс контроля качества:
* Написаны тесты с использованием `pytest` (`v2/tests/`).
* Настроен линтер **flake8** (конфиг — `.flake8` в корне) и форматтер **black**.
* Реализована автоматическая проверка кода при каждом пуше через **GitHub Actions**:
  установка зависимостей → flake8 → black → pytest.

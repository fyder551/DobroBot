# VK-бот для волонтеров

Проект представляет собой чат-бота ВКонтакте, созданного для автоматизации внутренней деятельности волонтерского отряда. Бот позволяет создавать анонсы мероприятий, собирать заявки на участие, управлять ролями и вести учет посещений.

## 🚀 Стек технологий
* **Язык:** Python 3.12
* **Библиотеки:** vkbottle (для работы с VK API), SQLAlchemy (ORM), dotenv.
* **База данных:** SQLite (с оптимизацией WAL).
* **Тестирование:** Pytest, Unittest.mock.
* **Инструменты:** Git, GitHub Actions (CI), flake8, black.

## 🛠 Реализованный функционал
* **Для волонтеров:** Регистрация (с валидацией ФИО), поиск мероприятий, отклик в один клик, личный кабинет со статусами откликов.
* **Для организаторов:** Создание мероприятий (FSM-диалог), указание лимитов, бонусов и ссылок на чаты, просмотр списка записавшихся.
* **Для администраторов:** Модерация заявок (одобрение/отклонение), управление ролями, отметка присутствия волонтеров (чек-боксы).

## 🧪 Тестирование
В проекте настроен процесс контроля качества:
* Написаны **Unit-тесты** с использованием `pytest` для проверки бизнес-логики (валидация данных, лимиты).
* Настроен линтер **flake8** и форматтер **black** для соблюдения стандартов PEP8.
* Реализована автоматическая проверка кода при каждом пуше через **GitHub Actions** *(В разработке)*.

## 💻 Как запустить локально
1. Склонируйте репозиторий:
   `git clone https://github.com/fyder551/DobroBot.git`
2. Создайте виртуальное окружение и активируйте его:
   `python -m venv venv`
   `venv\Scripts\activate` (для Windows)
3. Установите зависимости:
   `pip install -r requirements.txt`
4. Создайте файл `.env` и добавьте свои токены (VK_TOKEN, ADMIN_ID).
5. Запустите бота:
   `python run.py`
